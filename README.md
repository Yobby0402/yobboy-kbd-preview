# Yobboy Studio Preview

Temporary public preview of Yobboy Studio.

Website: https://yobby0402.github.io/yobboy-kbd-preview/

This repository contains only reviewed, compiled website assets and third-party
license notices. It does not contain the private development repository,
manufacturing tools, circuit designs, or backend services.

Configuration prices and checkout are demonstrations. No real orders or payments
are processed. Designs and uploaded images are stored in the visitor's browser.

Updates are published manually from the private development workspace. The
preview may be unpublished after the website moves to its own server.

Third-party dependency notices are in `licenses/`. Their licenses apply to the
respective dependencies; this repository does not grant a separate open-source
license to the Yobboy application or brand assets.
